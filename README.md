Advertising inside ChatGPT stopped being speculation in February 2026 and is now a channel you can buy, with a signup, a console and named brands already running in it. It is worth testing if your category involves people comparing options before they commit, because that is the moment the format is built around. It is not worth planning around if your audience skews toward paid subscribers, since the entire pilot excludes them by design. The caveat is maturity: the format is described by the vendor as a test that keeps changing, so treat budgets as experiments.
